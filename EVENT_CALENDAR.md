# event_calendar — календарный фильтр входов для Si (MOEX FORTS)

Модуль блокирует (или помечает) окна повышенной волатильности на основе анализа
двух лет дневных данных и двух месяцев M5-данных Si. Все расчёты — в таймзоне
Europe/Moscow; на вход принимаются как naive datetime (считается уже МСК), так
и aware (конвертируется в МСК).

## Файлы

```
event_calendar.py        — календарь событий: event_status / is_entry_blocked / next_event
cbr_dates.csv             — даты заседаний ЦБ РФ 2024-2026 (date,note)
splice_guard.py           — маркировка фиктивных гэпов склейки контрактов в OHLCV
backtest_filter_demo.py   — A/B/C-демо бэктеста с/без календарного фильтра
tests/test_event_calendar.py — pytest
```

## Таблица окон

| Флаг | Окно (МСК) | Блокирует вход? |
|---|---|---|
| `CBR_DAY` | весь день заседания ЦБ | нет (информационный) |
| `CBR_HOT` | 13:00–15:30 в день заседания ЦБ | **да, жёстко** (`hard_only=True` тоже блокирует) |
| `CPI_WINDOW` | среда 18:45–19:30 (недельная инфляция) | да, мягко |
| `CLEARING` | 14:00–14:05 и 18:50–19:05, будни | да, мягко |
| `TAX_PERIOD` | 25–28 число месяца | нет (информационный) |
| `EXPIRATION` | третий четверг мар/июн/сен/дек | нет (информационный) |
| `EXPIRATION_ADJ` | ±2 торговых дня от экспирации | нет для входа, но исключается из бэктеста (`splice_guard`) |

Границы окон — полуоткрытые интервалы `[начало, конец)`: например, для `CBR_HOT`
13:00:00 уже блокирует, 15:30:00 — уже нет.

**Обоснование блокировок** (из анализа данных):
- `CBR_HOT` — день ЦБ показал размах в 1.6–7 раз выше нормы;
- `CPI_WINDOW` — медиана движения нулевая, но хвосты до 3300 пунктов;
- `CLEARING` — торги фактически останавливаются, после — всплеск;
- `TAX_PERIOD` — 69 налоговых дней против 331 обычного не показали направленного
  смещения (50.7% красных против 52.3%) — оставлен информационным, не блокирует;
- `EXPIRATION_ADJ` — на склейке гэпы контанго до +5498/+3981/+3485 пунктов —
  это не движение рынка, поэтому не блокирует вход, но такие сделки исключаются
  из результатов бэктеста через `splice_guard`.

## Ограничения

- Даты заседаний ЦБ 2024–2025 в `cbr_dates.csv` требуют сверки с
  `cbr.ru/dkp/cal_mp` — при добавлении сверялись по памяти/косвенным источникам,
  даты 2026 года проверены по календарю ЦБ.
- «Торговый день» для `EXPIRATION_ADJ` считается как будний день (пн–пт).
  Праздники и внеплановые нерабочие дни MOEX не учитываются — модуль не имеет
  зависимости от торгового календаря биржи.
- `CLEARING` и `CPI_WINDOW` игнорируются в выходные (сб/вс), так как в реальных
  M5-данных баров в эти дни не бывает.

## Пример использования

```python
from datetime import datetime
from event_calendar import event_status, is_entry_blocked, next_event, EventFlag

dt = datetime(2026, 2, 13, 13, 15)  # день ЦБ, 13:15 МСК

event_status(dt)                    # EventFlag.CBR_DAY|CBR_HOT
is_entry_blocked(dt)                # True — мягкий фильтр (включает CBR_HOT)
is_entry_blocked(dt, hard_only=True) # True — жёсткий фильтр тоже блокирует CBR_HOT

next_event(dt)  # (ближайший следующий datetime, флаг, который включается)
```

Интеграция с бэктестом на pandas:

```python
from splice_guard import mark_splice_gaps
from event_calendar import is_entry_blocked

df = mark_splice_gaps(df)  # добавит df["splice_suspect"]

for ts in signal_timestamps:
    if is_entry_blocked(ts):        # мягкий фильтр
        continue                     # пропускаем вход
    ...
```

Полный A/B/C-прогон (без фильтра / мягкий / жёсткий) с готовыми метриками
(число сделок, winrate, средний PnL, профит-фактор, макс. просадка):

```
python backtest_filter_demo.py path/to/m5.csv
```

Сигнальная функция `signal_func` в `backtest_filter_demo.py` — заглушка,
замени её на свою логику паттерна «3+1» (сейчас там условный пробойный
плейсхолдер, только чтобы демо давало не пустой набор сделок).
